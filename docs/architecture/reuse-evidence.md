# §A-REUSE-01 — Поиск повторного использования опирается на исполняемые дескрипторы

Статус: принято.

## Решение

Переносимый `find-reuse` хранит обязательные адаптеры источников как данные с
фиксированными базовыми URL рабочей среды, шаблонами argv/URL, пробами,
типизированными ошибками и датой проверки реальным запуском. Автономная проверка
валидирует схему и исполняет те же шаблоны против локальных дублёров; отдельная
проверка с доступом к сети проверяет рабочие конечные точки, и только её
доказательство разрешает менять `last_verified`.

Дескриптор не является слоем адаптеров среды выполнения: скил остаётся
методологией только для чтения и запускает доступные инструменты напрямую.
Структурированный контракт нужен, чтобы проза, фикстуры и фактическая команда не
расходились.

Решение служит §B-FRAMING-04, §B-PROOF-01 и §B-PORTABILITY-03.

## Если §A-REUSE-01 отменяется

Станут лишними дескрипторы, их схема, фикстуры, проверки реальным запуском и
проверка дат. Проза снова станет единственным источником команд, поэтому принять
такую отмену можно только вместе с другим машинно проверяемым доказательством
полноты поиска.
