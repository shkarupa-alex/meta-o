# §A-QUIZ-01 — Квиз владельца — ручной лист, который только читает

Статус: принято.

## Решение

`mo-quiz` — лист графа §A-ACTIVATION-01: его запускает только прямой вызов
человека, ни один `mo-*` его не вызывает, и общий вопрос «что мы сделали?» его
не активирует. Это не ревью и не этап завершения жизненного цикла.

Входы скила — диапазон `merge-base(develop)..HEAD` и его коммиты, принятая
спецификация, если она есть, дословный журнал намерений и реплики текущего
диалога, а также изменения `docs/business.md` и `docs/architecture/`.
Незакоммиченное помечается отдельно; ради квиза ничего не коммитят. Журналы
сессий читаются только через `mo-debug`.

Сбор ведут три свежих сабагента без наследования контекста: объём и архитектура,
история и исправления, намерения. Без сабагентов — три последовательных прохода
с честной пометкой. Каждое найденное решение получает атрибуцию
`owner_intent(<ref>)`, `agent_choice` или `unclear`; текст в спецификации сам по
себе не доказывает происхождение от владельца.

Граница записи: скил ничего не пишет в репозиторий, журнал, бэклог или Issue без
явного согласия владельца после его ответов. Метрики процесса выводятся
отдельным блоком только из наблюдаемых данных; доли времени без данных о времени
не выводятся.

Решение служит §B-HUMAN-05 и §B-HUMAN-01.

## Если §A-QUIZ-01 отменяется

Станут лишними скил `mo-quiz`, его eval-кейсы и лист в графе активации. Владелец
снова будет восстанавливать картину решений агента вручную по диффу и истории.
