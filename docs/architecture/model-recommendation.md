# §A-MODELS-01 — Рекомендация выводится из каталога и ограниченной истории

```yaml
knowledge_id_changes:
  - action: reuse
    id: §A-MODELS-01
    reason:
      Review уточнил честность depth cutoff и полностью устранил model-id из
      executable recommendation tie-breaks.
    new_boundary:
      Recommendation требует coding positioning и offered high; ambiguity
      возвращается человеку, а усечённое history всегда partial.
    references_updated: true
  - action: reuse
    id: §A-MODELS-01
    reason: >-
      Решение не разделяло рекомендацию человеку и обязательные координаты
      эвалов, поэтому появление именованного клапана повышения не имело
      владельца: рекомендация могла вывести повышение сама.
    new_boundary: >-
      Возможное повышение обязательной координаты читается только записью в
      §A-EVAL-01; рекомендация его не выводит из каталога, истории или силы
      модели и при отсутствии записи не подставляет более сильную координату.
    references_updated: true
```

## Решение

`mo-models.mjs --catalog --project <root> --json` публикует
`meta-o.model-discovery.v2`: авторитетный каталог каждого маршрута и уникальные
идентификаторы моделей из обычных файлов сессий без символических ссылок за 31
день. Поиск сортируется по времени изменения и пути, ограничен 5000 ms и 64 MiB
на поставщика, не возвращает байты запросов и честно сообщает о нечитаемом,
повреждённом или частичном вводе. Защитное ограничение глубины не выдаётся за
полный обход: каждое отсечённое поддерево переводит историю в `complete: false`,
`stopReason: partial` и перечисляется ограниченным списком.

Рекомендация по умолчанию требует указания пригодности для кода в каталоге,
встроенном описании или официальных полях `label`, `description` либо
`capabilities` и фактически предлагаемого уровня рассуждений `high`. Текущие
ориентиры — `codex/gpt-5.6-sol/high` и `claude/opus[1m]/high`; это не селектор и
не постоянная прошивка. Единственный допустимый кандидат каталога может быть
рекомендован с любым идентификатором; при нескольких кандидатах
детерминированным решающим признаком служит только единственное совпадение с
недавней историей. Текущие ориентиры остаются подсказкой человеку и не
становятся исполняемым списком разрешений. Неоднозначность не разрешается
догадкой по имени. Astra/Fable показываются в полном списке, но без указания
пригодности для кода не рекомендуются по умолчанию. Без допустимого
доказательства результат — `no_default_recommendation`; явный выбор пользователя
остаётся авторитетным, а резервный путь запрещён.

Обязательные координаты эвалов эта рекомендация не выбирает: их задаёт
§A-EVAL-01, и возможное повышение обязательной координаты отдельного скила
читается оттуда же — записью в политике, а не выводом из каталога, недавней
истории или относительной силы модели. Нет записи — нет повышения, и подставить
более сильную координату «чтобы прошло» нельзя: доказательство привязано к
профилю, на котором выполнилось, и молчаливая подмена профиля обесценила бы всю
матрицу.

Решение служит §B-PORTABILITY-07 и §B-EVAL-01. Без §A-MODELS-01 недавняя история
снова выдаётся за каталог, рекомендация становится догадкой по имени модели, а
ограниченный контракт приватности, ресурсов и поиска теряет владельца.
