# §A-DIAGNOSTICS-01 — Диагностика читает только собственные журналы и остаётся локальной

```yaml
knowledge_id_changes:
  - action: reuse
    id: §B-SESSION-02
    reason: >-
      Владелец хочет видеть, где его собственные агенты разошлись со скилами, а
      единственный след этого — локальные журналы Claude и Codex, которые
      §B-SESSION-02 запрещал читать без исключений.
    new_boundary: >-
      Явно вызванная человеком диагностика может прочитать ограниченный набор
      его собственных журналов и выдать только локальный обезличенный отчёт;
      такое чтение не доказывает исполнение ревью или оркестрации, а источник
      финального ответа по-прежнему только публичная поверхность бэкенда.
    references_updated: true
  - action: reuse
    id: §A-DIAGNOSTICS-01
    reason: >-
      Метка `source_tree` приписывала версию по одному совпадению метки, хотя
      неполное чтение или установленный файл, изменённый после сборки, сохраняют
      старую метку при других байтах.
    new_boundary: >-
      Версия приписывается только полному тексту, побайтово равному
      закоммиченному файлу; видимая метка лишь сужает кандидатов до коммитов с
      той же меткой и всегда выводится отдельно как наблюдение.
    references_updated: true
```

## Решение

`mo-debug` запускается только по прямому вызову человека. Он принимает явные
пути или идентификаторы сессий и ограничение по времени или числу записей.
Помощник `mo-debug.mjs scan` читает только обычные файлы под
`~/.claude/projects/` или `~/.codex/sessions/`, которые принадлежат вызвавшему
пользователю. Символическая ссылка, чужой путь, неоднозначный или ненайденный
идентификатор получают типизированный отказ, и файл не читается. Сессий не
больше ста, записей в каждой — не больше заданного предела; достигнутый предел
делает результат `partial`, а нераспознанный формат — `unknown`, а не пустым
успехом.

Помощник только извлекает доказательства: вызовы скилов, загруженные тексты
скилов и запуски помощников `mo-*` с их типизированными строками. Классифицирует
их агент по закрытому набору
`skill_text_defect|agent_deviation|backend_defect|harness_defect|unknown`, и
каждое утверждение ссылается на номер записи сессии. Любой байт из журнала
проходит обезличивание до выхода: учётные данные заменяются типом, абсолютный
путь сокращается до `<path>/<basename>`, выдержка ограничена. Идентификаторы,
которые лишь выглядят случайными, — SHA, UUID, id модели — остаются дословными,
потому что по ним называют версию и сессию.

Версия загруженного скила приписывается только по закоммиченной истории и только
полному тексту: показанный текст сравнивается побайтово с закоммиченными
`skills/<name>/SKILL.md` по той же нормализации, что применяет harness, потому
что закоммиченный файл — сохранённый артефакт с доказуемым происхождением.
Сборка пишет в `metadata.source_tree` Git tree id входов скила (см.
§A-DISTRIBUTION-06), и видимая в сессии метка лишь сужает сравнение до коммитов,
где закоммиченный файл несёт ту же метку. Одной метки мало: неполное чтение и
установленный файл, изменённый после сборки, сохраняют старую метку при других
байтах. Claude показывает агенту текст без заголовка и без метки, поэтому его
тело сравнивается с закоммиченными телами. Нет совпадения, нет текста или текст
неполон — версия `unknown`, а увиденная метка выводится отдельным полем как
наблюдение, а не как версия. Текущий установленный текст никогда не
приписывается исторической сессии.

Результат — строки `MO-DEBUG/1` в stdout и, по просьбе, один новый локальный
файл отчёта с правами `0600`; существующий файл не перезаписывается. Помощник не
изменяет сессии, ничего не публикует и не создаёт Issue: черновик внешней записи
уходит только через отдельно активированный и уполномоченный скил жизненного
цикла по §A-ISSUE-01. Чтение журналов не служит доказательством исполнения ревью
или оркестрации: эти доказательства по-прежнему берутся только с публичных
поверхностей бэкенда.

Решение служит §B-SESSION-02, §B-HUMAN-03 и §B-CONTROL-04. Без §A-DIAGNOSTICS-01
отклонения агентов от скилов видны только по памяти человека, а исключение для
журналов становится лишним вместе со скилом `mo-debug`.

## Отклонено

- **Чтение чужих сессий или любых файлов по шаблону.** Владение доказывается
  путём и владельцем файла, а не догадкой о том, чья это сессия.
- **Приписывание версии по установленной копии.** Установленная копия
  показывает, что стоит сейчас, а не что агент читал тогда.
- **Публикация из `mo-debug`.** Внешняя запись требует отдельного разрешения и
  своего владельца.
