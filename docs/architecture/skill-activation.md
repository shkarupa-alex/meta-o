# §A-ACTIVATION-01 — Скилы Meta-O запускаются только по явному графу

```yaml
knowledge_id_changes:
  - action: reuse
    id: §A-ACTIVATION-01
    reason: >-
      Терминальный ревьюер получал задачу координатора и мог сам запустить
      `mo-review-orca`; отдельного скила ревьюера в графе не было.
    new_boundary: >-
      `mo-reviewer` входит в явный граф: его называет активный `mo-review-orca`
      в каждом Dispatch ревьюера и ставит из той же установленной сборки, а сам
      ревьюер координатора не запускает; без установленного `mo-reviewer`
      Dispatch не стартует.
    references_updated: true
  - action: reuse
    id: §A-ACTIVATION-01
    reason: >-
      Затянувшаяся работа и отклонения агентов от скилов разбирались вручную: в
      графе не было ни диагностики сходимости, ни чтения собственных журналов.
    new_boundary: >-
      `mo-convergence` и `mo-debug` входят в граф как листья только по прямому
      вызову человека; ни один `mo-*` их не вызывает, и общий запрос о задержке
      или отладке их не запускает.
    references_updated: true
```

## Решение

Любой `mo-*` применяется только по явному имени пользователя либо из уже
активного `mo-*`, который объявляет точного вызываемого. Описание в метаданных
заголовка начинается с условия явного вызова и не содержит общего триггера ревью
или настройки. Один AST-раздел `## Meta-O calls` содержит только имена
вызываемых скилов во встроенном коде либо `- none`; ссылки вне него не создают
скрытое ребро.

`mo-reviewer` — лист графа: его называет активный `mo-review-orca` в каждом
Dispatch ревьюера, и скил берётся из той же установленной сборки, что и
координатор. Терминальный ревьюер не запускает координаторский `mo-review-orca`
и не создаёт других исполнителей. Если у ревьюера нет установленного
`mo-reviewer`, Dispatch не стартует и готовность даёт
`needs_attention/skill_unavailable`; текст из непроверенной копии не
подставляется.

`mo-convergence` и `mo-debug` — тоже листья, но их не вызывает ни один `mo-*`:
оба запускаются только прямым вызовом человека. Общая просьба разобраться,
почему работа затянулась, или отладить сессию их не запускает, потому что первый
опрашивает живых участников, а второй читает журналы, и оба решения принадлежат
человеку.

`find-reuse`, `senior-jsts` и `senior-python` сохраняют узкую неявную
применимость. Детерминированный линтер сравнивает исходный и сгенерированный
графы, а проверка реальным запуском проверяет почти совпадающие запросы.

Решение служит §B-HUMAN-01 и §B-PORTABILITY-03. Без §A-ACTIVATION-01 среда
агента может сама запустить дорогой жизненный цикл по общему запросу, а граф
вызовов и фикстуры отсутствия активации становятся лишними.
