# Debt found outside a feature's scope

Debt *inside* a feature's scope is fixed by that feature. This file exists for
the other kind: the problem a run genuinely found, in code the spec never
claimed, which must neither be silently fixed — that widens the reviewed change
— nor silently forgotten.

One short entry each: area, risk, and the shape the future feature would take.
Nothing here is a commitment, and nothing here is a backlog to be groomed by
this workflow; a full architecture audit is a separate tool's job.
