# Бэклог

Здесь находится временная записная книжка только активной feature branch.
Подтверждённая работа вне scope живёт в project или upstream Issues, а не здесь.

Каждая временная запись — раздел третьего уровня с полями `Причина.`,
`Практическое влияние.` и `Следующий шаг.`. Перед завершением lifecycle каждая
запись получает disposition, после чего раздел открытых записей снова пуст.
